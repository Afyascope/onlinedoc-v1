# OnlineDoc Documentation

Welcome to the OnlineDoc documentation.

This directory is the primary source of truth for the project. Every architectural decision, business rule, feature specification, API contract, database design, development process, and deployment guide is documented here before implementation.

## Documentation Principles

The project follows a documentation-first approach.

Before writing code:

1. Define the problem.
2. Document the requirements.
3. Design the solution.
4. Review the design.
5. Implement.
6. Test.
7. Update documentation if changes occur.

Documentation evolves together with the application.
